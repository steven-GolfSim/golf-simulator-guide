# Golf Simulator Guide

A lightweight static site prepared for GitHub Pages. It includes a responsive homepage, shared styling, and a starter article.

## Publish with GitHub Pages

1. Create a public GitHub repository, ideally named `golf-simulator-guide`, with `main` as its default branch.
2. Add every file in this project to the repository root, keeping the `articles` folder intact.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/(root)` folder, then save.

The site should become available at:

`https://steven-golfsim.github.io/golf-simulator-guide/`

## Add another article

Copy the existing file in `articles`, give the copy a short lowercase filename, and update its title and body. Add a matching article card to `index.html`.
